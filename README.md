# RNA Folding Lab

A web app that predicts the secondary structure of an RNA molecule from a sequence you enter. It was built with Manus.

## What it does

- Takes an RNA sequence (A, U, G, C) as input
- Predicts how the sequence folds into a secondary structure
- Shows the result so you can explore it

## Live demo

https://rnafoldlab-4uqwaehm.manus.space

## Running locally

1. Install Node.js from https://nodejs.org
2. In the project folder, run `npm install`, then `npm run dev`
3. Open the local address shown in the terminal

Check `package.json` for the exact scripts available in this project.

## Notes

- The folding method used is not documented yet.
- Predictions are for learning and exploration, not for research or clinical use.
